# ESP8266 OTA

This section contains experiments with Over-The-Air firmware updates on ESP8266.

## OTA Firmware Update

The project explores remote firmware updating using:

* ArduinoOTA
* ESP8266 HTTP update functionality
* HTTPS communication
* LittleFS
* ArduinoJson
* Wi-Fi connectivity

The project also includes device configuration and display functionality as part of the broader embedded system.

## Topics Covered

* OTA firmware updates
* ESP8266
* HTTPS
* Wi-Fi
* LittleFS
* JSON configuration
* Remote firmware deployment

## Purpose

The project was developed to explore how firmware can be updated remotely without physically connecting the microcontroller to a computer.
