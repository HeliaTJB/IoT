# ESP32 Networking

This section contains experiments focused specifically on networking and server-side communication using ESP32.

## Network Server

The `network-server` project demonstrates the implementation of a network server on an ESP32 using Wi-Fi and asynchronous networking.

## Topics Covered

* ESP32 Wi-Fi
* Network servers
* Asynchronous communication
* TCP/IP networking
* Client-server architecture

## Purpose

The project was developed to explore how an ESP32 can act as a network-connected server and communicate with external clients.
