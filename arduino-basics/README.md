# Arduino Basics

This section contains basic Arduino and microcontroller experiments developed while learning fundamental concepts of embedded systems.

The projects cover introductory hardware interaction, digital I/O, displays, and other basic microcontroller programming exercises.

## Projects

### 7-Segment Display

Basic control of a TM1637-based 7-segment display.

### P6 – P9

A collection of practical exercises developed during the early stages of working with Arduino and embedded systems.

## Topics Covered

* Digital I/O
* GPIO control
* 7-segment displays
* Basic embedded programming
* Arduino sketches
* Hardware interfacing

## Platform

* Arduino
* Compatible microcontroller boards

These projects are primarily educational and represent different stages of learning and experimentation.
