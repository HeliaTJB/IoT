# ESP32 IoT Basics

This section contains a collection of ESP32-based IoT experiments focusing on wireless communication, HTTP/HTTPS requests, sensors, displays, and remote control of hardware.

The projects represent different stages of experimenting with IoT concepts and connecting embedded devices to network-based services.

## Projects

### LED over HTTP

An ESP32 project demonstrating remote LED control through HTTP communication.

### Temperature over HTTP

A temperature-monitoring project using a DHT11 sensor and HTTP communication to transmit sensor data.

### Touch over HTTP

An ESP32 project combining touch input with network communication and remote control.

### RGB over HTTPS

A project demonstrating RGB LED control using Wi-Fi and HTTPS-based communication.

### P10 Display

An experiment involving a P10 LED display and network connectivity.

### P11

An ESP32-based IoT exercise combining hardware control and HTTP communication.

## Topics Covered

* ESP32
* Wi-Fi
* HTTP / HTTPS
* REST-style communication
* Sensor data transmission
* Remote hardware control
* LED and RGB control
* Touch input
* Network-connected displays

## Purpose

These projects were developed as practical experiments for understanding how embedded devices can communicate with external services and be controlled over a network.
