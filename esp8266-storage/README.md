# ESP8266 Storage

This section contains experiments with non-volatile storage on ESP8266, including EEPROM and LittleFS.

## Projects

### EEPROM

Experiments with storing and retrieving string data using EEPROM.

### LittleFS

An ESP8266 web server experiment using LittleFS for file storage and file uploads.

The project demonstrates how files can be stored on the device's flash memory and accessed through a web interface.

### LittleFS File Write

A smaller experiment demonstrating writing data to a file stored in LittleFS.

## Topics Covered

* EEPROM
* LittleFS
* Flash-based file storage
* File read/write operations
* ESP8266 Web Server
* HTML file storage
* Embedded persistent storage

## Purpose

These experiments were developed to understand how ESP8266 devices can store configuration and other data persistently between reboots.
